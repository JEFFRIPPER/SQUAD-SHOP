# SQUAD SHOP

Магазин T.N.K.C SQUAD: звёзды Telegram и Premium за рубли, оплата через ЮMoney.

- Витрина: `index.html`, `style.css`, `app.js`.
- Товары и настройки (кошелёк ЮMoney, поддержка): `shop.json`. Править удобнее с самого сайта: откройте `/#admin`, войдите ключом GitHub с правом записи в этот репозиторий, кнопка «Товары».
- Хостинг: GitHub Pages из ветки `main`.
