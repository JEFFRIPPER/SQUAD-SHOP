# SQUAD SHOP

Магазин T.N.K.C SQUAD: звёзды Telegram и Premium за рубли, оплата через ЮMoney.

- Витрина: `index.html`, `style.css`, `app.js`.
- Товары и настройки (кошелёк ЮMoney, поддержка, ключ Web3Forms для писем о заказах): `shop.json`. Править удобнее с самого сайта: откройте `/#admin`, войдите ключом GitHub с правом записи в этот репозиторий, кнопка «Товары».
- Хостинг: GitHub Pages из ветки `main`.
- Заказы: при нажатии «Оплатить» сайт шлёт владельцу письмо через Web3Forms (номер SQ-…, @username, состав, сумма), а когда покупатель возвращается с ЮMoney, второе письмо. Оплату сверяйте в истории ЮMoney по метке SQ-….
